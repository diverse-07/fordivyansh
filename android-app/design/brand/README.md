# LibreVision identity

The LV monogram and guiding dot share one SVG master: [librevision-mark.svg](librevision-mark.svg). The mint tile is the app icon; monochrome marks adapt to the app's Field and Night themes.

Use the icon for launcher/store artwork and the wordmark for horizontal branding. Keep clear space around the mark. Do not stretch it or replace navigation/settings icons with it.

Regenerate Android vectors, adaptive/themed icons, splash artwork, wordmarks and the HTML reference with `python3 scripts/generate_brand.py`, then run `python3 scripts/format_code.py`.
