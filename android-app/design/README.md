# LibreVision design

Open [LibreVision_Industrial_Prototype.html](LibreVision_Industrial_Prototype.html) directly in a browser. It is self-contained and works offline.

Includes six screens, Field/Night finishes, large SVG icons, a movable camera overlay, and a Muse interaction preview. Review controls sit outside the proposed app UI.

Camera scenes, maps, distances and Muse replies are simulated. No camera, microphone or model API is accessed. Explicit audio controls use local browser audio where supported.

Edit the CSS theme variables, SVG symbols, screen sections and JavaScript `DESIGN` object in the HTML. The approved design is implemented natively in the Android app; later HTML edits must be ported separately.

References: [OP–1 field](https://teenage.engineering/products/op-1) and [K.O. II](https://teenage.engineering/products/ep-133). Development notes and rendered previews remain local and are ignored by Git.
